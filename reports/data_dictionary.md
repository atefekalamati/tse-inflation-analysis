# Data dictionary

Generated by `src/process_data.py`.

## Conventions

- Dates are Jalali (`YYYY-MM-DD`, months `YYYY-MM`). Gregorian dates are in `date_greg`.
- Prices are in rial. Index values are in index points. Returns are fractions (0.05 = 5%).
- Stock prices use TSETMC's official closing price (قیمت پایانی), not the last trade.
- Adjusted prices come from algotik-tse 1.8.0, which back-adjusts every earlier price by (next day's reference price / closing price) at each ex-date. Returns on adjusted prices therefore include cash dividends and capital increases. Rights issues paid in cash are treated like bonus shares, which slightly overstates returns around them.
- CPI is the Statistical Centre of Iran's index for all households of the whole country, base 1400 = 100. SCI collects prices from the 1st to the 28th of each month, so a month's CPI is an average over the month while stock returns are end-of-month to end-of-month.
- Market-closed days: 61 days on which TSETMC published a flat, zero-volume index row. They are kept and flagged, never counted as stock suspensions.

## prices_daily.parquet

12,563 rows: 17 series x 739 calendar days (1402-06-01 to 1405-06-31). Key: (code, date_jalali).

| column | dtype | unit | definition |
|---|---|---|---|
| date_jalali | str | text YYYY-MM-DD | Trading-calendar date (Jalali). The calendar is every day on which TSETMC published شاخص کل, including market-closed days. |
| date_greg | datetime64[us] | date | Same date in the Gregorian calendar. |
| symbol | str | text | Series name: stock ticker, sector label as in config, or market index name. |
| code | str | text | ASCII identifier of the series (stable key for joins and file names). |
| type | str | stock / sector_index / market_index | Kind of series. |
| sector | object | text | Sector label from config/settings.yaml (for stocks and sector indices); empty for market indices. |
| close_adj | float64 | rial (stocks) / index points | Stocks: official closing price (قیمت پایانی, TSETMC `Final`) back-adjusted for capital increases and dividends by algotik-tse, anchored at 1405-06-31 and truncated to integer rial. Indices: closing index value (corrected where `was_corrected`). Empty when the stock did not trade. |
| close_unadj | float64 | rial / index points | Stocks: unadjusted official closing price. Indices: same as close_adj. |
| volume | float64 | shares | Stocks: shares traded (unadjusted). شاخص کل: whole-market volume. Empty for other indices. |
| value | float64 | rial | Stocks: traded value. Empty for indices. |
| traded | bool | bool | Stocks: a trade row exists and the market was open. Indices: market open. |
| market_closed | bool | bool | One of the 61 days on which شاخص کل has zero volume and a flat value (market closed). No stock traded on these days. |
| suspended | bool | bool | Stock had no trade although the market was open (symbol-specific halt). |
| first_trade_after_halt | bool | bool | Stock trades today after at least one open-market day without trading. Market-closed days do not count as a halt. |
| halt_days_before | int64 | days | Number of consecutive open-market days without a trade immediately before this trade (0 otherwise). |
| adjustment_event | bool | bool | Ex-date of a corporate action: adjusted/unadjusted ratio changes by at least processing.min_adjustment_event (1%). |
| adj_factor | float64 | ratio | Factor applied to all earlier prices at this ex-date (e.g. 0.74 for a capital increase); 1 otherwise. |
| was_corrected | bool | bool | A value on this row was changed by a correction listed in reports/corrections.md. |


## prices_monthly.parquet

666 rows: 18 series x 37 months (1402-06 to 1405-06). Key: (code, month_jalali).

| column | dtype | unit | definition |
|---|---|---|---|
| month_jalali | str | text YYYY-MM | Jalali month. 1402-06 is the base month (no return); returns run 1402-07 to 1405-06. |
| symbol | str | text | Series name (as in the daily panel); `CPI` for the consumer price index. |
| code | str | text | ASCII identifier of the series. |
| type | str | stock / market_index / sector_index / cpi | Kind of series. |
| sector | object | text | Sector label (stocks and sector indices). |
| is_base_month | bool | bool | True for 1402-06. |
| close_adj_eom | float64 | rial / index points / CPI points | Last available adjusted close up to the end of the month (official closing price for stocks). If the series did not trade in the month, the previous month's value is carried forward. For CPI: the CPI value. |
| close_date_jalali | object | text YYYY-MM-DD | Date of the price used in close_adj_eom. |
| close_carried_forward | bool | bool | No price in this month; close_adj_eom carried forward from an earlier month. |
| return_nominal | float64 | fraction | close_adj_eom_t / close_adj_eom_(t-1) - 1. Includes dividends and capital increases through the back-adjustment. For CPI: monthly inflation. |
| cpi_index | float64 | index, 1400=100 | SCI CPI, all households, whole country, for this month. |
| inflation_monthly | float64 | fraction | CPI_t / CPI_(t-1) - 1. |
| return_real | float64 | fraction | (1 + return_nominal) / (1 + inflation_monthly) - 1. For CPI: 0. |
| growth_nominal | float64 | index, 1402-06 = 100 | 100 x close_adj_eom_t / close_adj_eom_1402-06. For CPI: 100 x CPI_t / CPI_1402-06. |
| growth_real | float64 | index, 1402-06 = 100 | growth_nominal / (CPI_t / CPI_1402-06), i.e. purchasing power of 100 invested at the end of 1402-06. Equals 100 x cumulative product of (1 + return_real). Above 100 = beat inflation since 1402-06. |
| open_market_days | float64 | days | Days in the month on which the market was open. |
| trading_days | float64 | days | Stocks: days with a trade. Indices: open-market days. |
| market_closed_days | float64 | days | Market-closed days in the month. |
| suspended_days | float64 | days | Open-market days on which the stock did not trade. |
| market_closure_in_month | bool | bool | The month contains at least one market-closed day. |
| long_suspension | bool | bool | suspended_days >= processing.long_suspension_days (5). |
| no_trade_in_month | bool | bool | The series has no trade in the month (price carried forward, return 0 that month, the move lands in the month trading resumes). |
| data_flag | bool | bool | market_closure_in_month OR long_suspension OR no_trade_in_month. Treat monthly returns with this flag with care. |
| adjustment_event_in_month | bool | bool | A corporate-action ex-date falls in the month. |
| corrected_value_in_month | bool | bool | A corrected daily value falls in the month. |
