# Power BI dashboard: Did TSE stocks beat inflation? (1402-07 to 1405-06)

A Power BI Project (`.pbip`) with a TMDL semantic model and a PBIR report. Everything in this
folder is generated by `src/build_dashboard.py` from the CSVs in `data/processed/powerbi/`.
Do not edit the generated files by hand. Change the generator and rebuild instead.

```
python src/analysis.py          # refresh the CSVs (numbers come from the analysis, unchanged)
python src/build_dashboard.py   # rewrite dashboard/ and dashboard/measures.dax
```

## Open it

1. Open `tse_inflation.pbip` in Power BI Desktop (June 2026 release or later; PBIR and TMDL
   must be enabled, which is the default in current releases).
2. The CSV folder is a parameter, `DataFolder`. Its default is
   `E:\BI\mini\tse-inflation-analysis\data\processed\powerbi\`. On another machine, go to
   **Transform data > Edit parameters** and set it to that folder. Keep the trailing `\`.
3. Click **Refresh**.

## Model

| Table | Grain | Notes |
|---|---|---|
| `dim_series` | one row per series (19) | `type` = stock / market_index / sector_index / portfolio / cpi; `series_fa` sorted by `sort_order` |
| `dim_month` | one row per Jalali month (1402-06 to 1405-06) | month-grain time dimension; `month_label_fa` sorted by `sort_key` |
| `monthly_long` | series × month | monthly returns, growth indices (1402-06 = 100), rolling 12-month real return |
| `risk_summary` | series | CAGR, cumulative 3-year, volatility, drawdown |
| `yearly_real` | series × 12-month block | real return per year; `block_fa` = Persian block label |
| `closure_summary` | series × window | market closure, pro-rated and whole-month CPI |
| `correlation_long` | series pair (10 × 10: 8 stocks, 2 indices) | no relationships; `series_a_fa` and `series_b_fa` sorted like `dim_series` |
| `context` | one row | government bond (اراد) yield snapshot vs inflation; no relationships |
| `_Measures` | — | all 38 DAX measures, also in `measures.dax` |

- **Relationships:** `dim_series` has a one-to-many, single-direction relationship to
  `monthly_long`, `risk_summary`, `yearly_real` and `closure_summary`, joined on `series_code`.
  `dim_month` relates one-to-many to `monthly_long`, joined on `month`.
- **Hidden columns:** descriptive columns duplicated in the fact tables are hidden. Visuals take
  names from `dim_series[series_fa]`.
- **Auto date/time:** off. `dim_month` is not marked as a date table, because Power BI requires
  a contiguous daily date column for that and the analysis is monthly. It is the only time
  dimension in the model.
- **Formats:** percentages use `0.0%`. Growth indices use `0.0`. CPI growth is shown as `3.62×`.

## Report pages

Every page has a title, a one-line Persian subtitle with the page's main finding (computed from
the CSVs at build time), a method note and the footer «منبع: TSETMC و شاخص قیمت مصرف‌کننده
مرکز آمار ایران (۱۴۰۰=۱۰۰)».

1. **نمای کلی: بورس در برابر تورم.**
   - Five headline cards: CPI growth, overall-index real return, equal-weight real return, stocks
     beating inflation, and the closure real loss.
   - Real growth chart of the two market indices against CPI = 100.
   - Rolling 12-month real return.
   - Nominal against real CAGR. Real bars are green `#2E7D32` above 0 and red `#C62828` below 0,
     coloured by the measure `Real CAGR color`.
   - Hindsight note on the 8 stocks.
   - Page filter: market indices and CPI.
2. **پراکندگی: ۸ سهم نمونه، نه کل بازار.**
   - A single-select slicer drives the five "Selected" cards only. They show the overall index
     when nothing is selected.
   - Real CAGR bars, green or red by sign.
   - Risk-return scatter.
   - Series × 12-month block matrix with a red-white-green colour scale centred on 0.
   - Risk table.
   - Page filter: stocks, market indices and the hindsight portfolio.
3. **تعطیلی بازار و دارایی «امن»**
   - Closure bar chart for the market indices, with CPI pro-rated to the exact dates.
   - Five bond and inflation cards, plus the conditional statement with its source and date.
   - Closure table for both windows, with pro-rated and whole-month figures.
   - Page filter: market indices and stocks.
4. **زمان ورود**
   - Rolling 12-month real return of the overall and equal-weight indices, with a constant line
     at 0.
   - Correlation heatmap from `correlation_long`: 8 stocks and 2 indices, white (0) to dark blue
     (1).
   - Page filter: market indices and stocks.

**Sector indices never appear.** Every page has a locked page filter on `dim_series[type]` that
excludes `sector_index`.

The theme is `theme.json`, also registered in the report: a blue palette with green and red, in
Segoe UI. `BUILD_GUIDE.md` (Persian) covers opening the project, changing `DataFolder`,
refreshing, the expected value of every card, what to check on each page, and manual fixes.

## How it was checked

`pytest tests/test_dashboard.py`:

- **Report JSON:** every report file is validated against Microsoft's PBIR JSON schemas, which
  are kept in `tests/pbir_schemas/`.
- **Field references:** every field the report uses must exist in the model.
- **Model rules:** the page filters, relationships, sort orders and formats are checked against
  the rules above.
- **TMDL parse:** `tools/check_tmdl.ps1` parses the TMDL with the serializer that ships with
  Power BI Desktop (`Microsoft.PowerBI.Tabular.dll`).
- **Engine run:** `tools/test_model_on_engine.ps1` starts Power BI Desktop's engine
  (`msmdsrv.exe`) headless. It deploys a test copy of the model and runs
  `tools/model_checks.dax`, and every measure result is compared with the CSVs.
  - The test copy uses the same measures, relationships and sort orders.
  - Its tables are DAX `DATATABLE`s built from the same CSVs, because a standalone engine cannot
    run Power Query. The Power Query steps (CSV parsing, types, the added columns `block_fa`,
    `window_fa`, `window_order`) therefore run for the first time when you refresh in Desktop.

Not checked: how the pages look. The layout was written as JSON and has not been opened in Power
BI Desktop yet.
